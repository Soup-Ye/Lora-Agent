# Lora-Agent
Lora 是一个面向 QQ 场景的可视化 AI 智能体系统，集成多账号接入、人设管理、知识库路由、上下文回忆、印象学习与自主日程，让智能体拥有持续的身份与互动体验。 系统支持自定义人设模板，为不同聊天对象应用不同设定，并按需读取知识库与功能规则，减少无关上下文和重复工具调用。通过可控的自主成长机制，智能体能够结合交流反馈更新印象、人际关系与群文化理解。 Lora 提供图片与表情包管理、空间互动、跨通道通讯等能力，优化降低模型调用负担。可视化操作台集中管理模型 API、账号、权限、日志与数据迁移，支持自定义 QQ 路径、端口冲突自动避让。 界面提供多种主题、自定义图片与动态背景、卡片式设置和功能搜索。无论是日常陪伴、群聊互动，Lora 都希望让复杂的智能体配置更直观，让个性化体验更易掌控。
