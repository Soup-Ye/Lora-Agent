# Lora-Agent
Lora 是基于QQ agnet项目二次开发的，一个面向 QQ 场景的可视化 AI 智能体系统。
1.集成多账号接入、人设管理、知识库路由、上下文回忆、印象学习与自主日程，拥有持续的身份与互动体验。
2.系统支持自定义人设模板，为不同聊天对象应用不同设定，并按需读取知识库与功能规则，减少无关上下文和重复工具调用。极大优化了对话轮次的消耗，并且设置了接话规则，用极小的消耗来不错过任何一条消息。
3.通过可控的自主成长机制，智能体能够结合交流反馈更新印象、人际关系与群文化理解。 让智能体具备自我性格成长改变，形成人际关系网，印象关系，自我生活习惯，对每个人都有一个自己形成的形象画像。不是所有人说话的人在她眼里都是一样的。
4.Lora 提供图片与表情包管理、空间互动、跨通道通讯等能力，优化降低模型调用负担。
5.可视化操作台集中管理模型 API、账号、权限、日志与数据迁移，支持自定义 QQ 路径、端口冲突自动避让。 拥有极简配置快速启动的功能，快速完成部署启动。
6.界面提供多种主题、自定义图片与动态背景、卡片式设置和功能搜索。
7.支持自定义skill和插件添加额外功能，支持接入额外拓展的工作包实现更强大的功能。
无论是日常陪伴、群聊互动，Lora 都希望让复杂的智能体配置更直观，让个性化体验更易掌控。
